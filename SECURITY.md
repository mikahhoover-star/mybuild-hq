# Security

Report potential security vulnerabilities privately to the repository owner rather than opening a public issue containing exploit details or customer information.

Do not post license keys, customer emails, order receipts, service-role credentials, API tokens, or passwords in GitHub issues.

The current production website is static. Work on server-side purchase entitlements and project-data access control is in a draft pull request and must not be considered deployed until release.

GitHub Pages source code is public; server-enforced authorization protects data, not the source code itself.

For customer support, use the seller's Gumroad support channel.
